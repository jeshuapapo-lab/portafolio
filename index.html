Informe

Descripción del proyecto

Este sitio funciona como una evidencia digital del proceso de formación técnica. No se limita a mostrar herramientas; presenta decisiones, proceso y resultados verificables.

Objetivo general

Diseñar y publicar un portafolio web funcional que permita demostrar conocimientos de informática mediante una presentación clara, navegable y revisable.

Alcance

Incluye estructura HTML, diseño responsive, enlaces funcionales, publicación en GitHub Pages y un recurso visual interactivo con JavaScript.

Competencias aplicadas

Organización de archivos, diseño de interfaz, control de enlaces, documentación básica, despliegue web y corrección de errores.

Resultado esperado

Una página estable, adaptable a distintos tamaños de pantalla y con evidencias accesibles para evaluación académica.

Metodología

El trabajo se presenta como una secuencia de decisiones técnicas, no como una lista genérica de habilidades.

01

Planificación

Se definieron las secciones necesarias: presentación, descripción del proyecto, metodología, evidencias y enlaces de verificación.

02

Construcción

Se implementó la página con HTML, estilos responsivos, navegación interna, tarjetas de información y enlaces externos.

03

Publicación

El proyecto fue subido a GitHub y publicado mediante GitHub Pages, permitiendo revisión desde cualquier navegador.

04

Verificación

Se revisaron enlaces, visualización, navegación y adaptación del diseño para corregir fallos antes de la entrega.

Evidencias

Elementos verificables

Repositorio

Código fuente visible, actualizable y disponible para revisión técnica.

Sitio publicado

Página activa en línea con navegación, diseño adaptable y enlaces funcionales.

Recurso interactivo

Elemento visual 3D como aplicación de JavaScript en la presentación.

Conclusión

Evidencia de aprendizaje progresivo

El portafolio muestra un proceso completo: idea, estructura, implementación, publicación y corrección. Su valor principal está en demostrar práctica real y capacidad de mejora continua.
