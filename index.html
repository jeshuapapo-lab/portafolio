Perfil

Formación aplicada, no solo herramientas

Diagnóstico del problema

Identifico qué se necesita resolver, separo el trabajo por partes y defino una solución antes de escribir código o configurar servicios.

Organización técnica

Uso estructura de archivos, nombres claros, enlaces funcionales y documentación básica para que el proyecto pueda revisarse sin confusión.

Validación y entrega

Reviso la navegación, pruebo la publicación, corrijo errores visibles y preparo el resultado para ser presentado académicamente.

Publicación

Aplicación técnica

Relación con redes, servicios, documentación y prácticas de informática.
